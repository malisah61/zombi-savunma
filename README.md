# Zombi Savunma

2D zombi dalgası savunma oyunu (Godot 4, Android). Askerini parmağınla sağa sola kaydır, o en yakın
zombiye kendisi ateş eder. Dalga aralarında yetenek kartı seç, altınla barikatı onar.

**APK:** https://github.com/malisah61/zombi-savunma/releases/download/son-surum/ZombiSavunma.apk

Oyun her gece otomatik olarak geliştirilir: plan `TASARIM.md`, yapılanlar `GUNLUK.md`.
Bir istek ya da hata bildirimi için `TASARIM.md` içindeki **Oyuncu İstekleri** bölümüne not ekle;
gece görevi önce onları yapar.
